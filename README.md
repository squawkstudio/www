# SquawkStudio GitHub Pages

This is a [public repo](https://github.com/squawkstudio/www) to just enable [Github Pages](https://pages.github.com/), with a branch named `gh-pages`.

There are subfolders in here that is published to by other repo, e.g. `www.timerz`.

This repo must be `public` per Github, but the subfolder repos can remain as `private`.

A simple `git push` would publish the contents, but be careful to not destroy the contents of the subfolders.
